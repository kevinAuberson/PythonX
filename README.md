# PythonX
Python par la pratique 2024-2025
## Objectifs 
A l'issue de cette unité d'enseignement l'étudiant sera capable d'installer et d'utiliser Python en parfaite autonomie sous Windows et dans un environnement POSIX.

Généralités :
- Installation d'un environnement Python sous Windows ou POSIX
- Utilisation de l'un interface interactive REPL IPython
- Utilisation de Jupyter Notebook
- Installation de paquets
- Environnements virtuels

Fondements du langage :
- Classes et fonctions
- Héritage
- Modèle de donnée Python (méthodes magiques, décorateurs, ...)
- Duck Typing
- Bibliothèques standards (collections, itertools, functools, math)
- Expressions régulières (re)
- Introspection (inspect)
- Exceptions
- Fonctions lambda
- List compréhensions

Applications par domaines :
- Numpy, Scipy (manipulation de vecteurs, et calcul scientifique)
- Flask (serveur web)
- Pandas (traitement de données)
- YAML, JSON (sérialisation et désérialisation de données)
- Ctype (interface avec C)
- Interfaces graphiques

Travail collaboratif :
- Tests
- PEP8
- Création et publication d'un packet Python avec setuptools
